# SYSTEM ERROR: REALITY NOT FOUND

Изометрическая приключенческая игра о цифровой реальности, которая начинает давать сбои. Игроку предстоит исследовать мир, находить баги, взаимодействовать с персонажами и сделать выбор, влияющий на концовку.

## Запуск

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/satrana24/web_game.git
   ```
2. Откройте папку проекта.
3. Запустите `index.html` через локальный сервер (например, расширение **Live Server** в VS Code).
4. Откройте игру в браузере.

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `↑` | Движение вверх |
| `S` / `↓` | Движение вниз |
| `A` / `←` | Движение влево |
| `D` / `→` | Движение вправо |
| `E` | Взаимодействие с объектами и персонажами |
| `Space` | Уворот |
| `Esc` | Пропуск кат-сцены |

Дополнительно:
- **Пауза** — приостановить игру.
- **Заново** — начать прохождение сначала.
- На мобильных устройствах доступны экранные кнопки управления.

## Особенности

- Поиск трёх багов.
- Диалоги и сюжетные кат-сцены.
- Несколько вариантов концовки.
- Система подсчёта времени и сохранения рекорда.
